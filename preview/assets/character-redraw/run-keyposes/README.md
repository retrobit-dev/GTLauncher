# Studi pose lari — belum siap dianimasikan

`front-study.png` dan `back-study.png` adalah referensi pose tunggal yang dibuat dari desain karakter bertopi. Keduanya bukan rangkaian animasi dan belum diterapkan di game.

Percobaan pose langkah berlawanan masih menghasilkan kaki dan lengan depan yang sama, sehingga dibuang. Jangan gunakan, membalik secara horizontal, atau menamainya sebagai langkah lawan: pencerminan juga membalik arah hadap dan detail tas. Diperlukan pose lawan yang digambar atau dirig dengan titik sendi, proporsi, pakaian dan perspektif yang cocok, serta pose antara dan pemeriksaan sambungan sebelum dapat dipakai sebagai siklus lari.
