# Suasana waktu

Warna langit dan tint pulau bertransisi kontinu dari malam melalui subuh atau
senja menuju siang menggunakan elevasi matahari dan lokasi; cuaca dan tutupan
awan tetap memengaruhi tampilan. Ini adalah pendekatan visual, bukan simulasi
atmosfer atau waktu ibadah. Pilihan demo preview mencakup Subuh dan Senja;
mode Live tetap memakai waktu dan data cuaca sebenarnya bila tersedia. Akses
lokasi/jaringan dapat gagal dan kemudian memakai fallback Rembang serta data
terakhir. Matahari dan bulan tetap disembunyikan sesuai keputusan sebelumnya.

Tes menguji kontinuitas bobot dan tampilan kedua pilihan demo di browser;
Android diuji model dan pemeriksaan tipe saja, belum melalui APK/perangkat.
