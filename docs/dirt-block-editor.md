# Block Tanah di Map Editor

Pilih **Block → Tanah**. Gunakan **Tambah block** untuk menambah satu tingkat di atas block atau mengisi sel kosong; **Ganti block** hanya mengganti tingkat teratas. **Hapus block** menghapus satu tingkat. Lihat `grass-block-editor.md` untuk riwayat, batas ketinggian, pemilihan block, dan aturan pergerakan.

Permukaan dan sisi tanah mengikuti palet hangat konsep. Tanah biasa tetap berbeda dari terrain lahan pertanian (kode 6); ini tidak menambahkan mekanik mencangkul atau menanam. World bertingkat memakai format preview versi 4 yang belum didukung Android. Penyimpanan preview dan Android terpisah.
