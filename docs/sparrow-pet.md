# Pet burung pipit

Konsep pipit yang dipilih digunakan sebagai pet kosmetik otomatis di gameplay. Burung terbang di atas kepala player ketika diam maupun bergerak, dengan kepakan dan gerakan naik-turun. Ketika player duduk, burung bertengger di atas topi; ketika player bergerak, burung kembali terbang. Arah burung mengikuti player dengan pose depan/belakang dan cermin. Di map editor pet tidak ditampilkan. Reduced motion menghentikan gerak dan kepakan.

Ini adalah pendamping visual awal, bukan sistem peliharaan penuh: belum ada pilihan/penyimpanan pet, interaksi, tabrakan atau pathfinding mandiri. Sayap menggunakan dua frame sederhana, bukan animasi terbang lengkap. Posisi burung mengikuti koordinat visual player, bukan tile tersimpan. Sprite transparan dibangun dari konsep terpilih dengan `tools/build_sparrow_pet.py` dan dibagikan oleh preview dan Android. Android memakai implementasi visual serupa tetapi belum diuji build atau perangkat. Perpindahan otomatis dari air masih hanya tersedia di preview, seperti dijelaskan di `player-idle-bow.md`.
