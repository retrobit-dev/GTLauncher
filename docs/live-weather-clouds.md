# Live weather dan bayangan awan

Live memakai kondisi saat ini dari model Open-Meteo untuk lokasi perangkat (jika izin dan lokasi tersedia), atau titik fallback Rembang (-6.7097, 111.3476). Itu estimasi model pada area/grid, bukan pengamatan hujan persis di halaman pengguna; hujan lokal dapat berbeda. Koneksi/izin lokasi dan pembaruan yang terlambat juga dapat menyebabkan perbedaan. Preview menampilkan koordinat sumber lokasi, waktu penerimaan data, waktu model Open-Meteo jika tersedia, kode, hujan, presipitasi, awan dan angin; tombol ↻ meminta pembaruan segera. Kegagalan diberi tanda dan data terakhir dipertahankan. Waktu model adalah waktu data model, bukan pengamatan di rumah pengguna; hujan dan presipitasi adalah akumulasi selama interval data model, bukan bacaan sensor lokal. Preview dan Android mencoba memperbarui setiap 10 menit; hasil tidak dijamin real-time. Demo cuaca preview tidak menggunakan kondisi live. Android belum menampilkan rincian status tersebut.

Sprite awan tetap disembunyikan. Preview kini mengikuti aturan Android: bentuk raster dan cermin, ukuran maksimal empat tile, 3–4 awan cerah dan minimal 5 untuk mendung/hujan, tersebar di grid; gerakan mengikuti angin dan independen dari player. Bayangan hanya di permukaan pulau, masker disatukan agar overlap tidak menumpuk gelap, blur dan fade bersama; reduced motion menghentikan gerakan dan fade. Tinggi awan ilustratif, bukan data ketinggian cuaca aktual. Posisi dan bentuk bayangan bersifat dekoratif, bukan prakiraan bayangan fisik. Android belum diuji pada build atau perangkat untuk perubahan ini.
