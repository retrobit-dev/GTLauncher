# Pohon jeruk

Konsep pixel art terpilih `preview/assets/character-redraw/orange-tree-pixel-proportional-concept.png` digunakan untuk sprite pohon dewasa berbuah; konsep dan sprite sebelumnya tetap disimpan. Proporsi gambar dijaga tanpa peregangan dan tinggi pohon tetap 60 unit dengan tapak logis 2×2. Dalam Map Editor preview, **Objek → Pohon jeruk → Tempatkan pohon jeruk**, lalu pilih sudut pertama tapak 2×2. Dapat ditempatkan lebih dari satu pada tanah rata tanpa air, lubang, rumah, pohon lain, atau player. Pohon menjadi rintangan jalur, bergoyang mengikuti angin (diam pada reduced motion), memiliki bayangan, tersimpan per world dan mendukung undo/redo penempatan dalam sesi editor. Perubahan block yang merusak tapak ditolak.

Pohon dapat dipilih langsung atau memakai alat Pilih di sebelah kiri tablet, kemudian diputar, dipindahkan, atau dihapus di Map Editor. Rotasi menyimpan empat arah, tetapi sprite sementara hanya memiliki dua tampilan cermin, bukan empat gambar arah yang berbeda. Penempatan, pemindahan, rotasi, dan penghapusan mendukung Undo/Redo selama sesi editor. Menebang, memanen, dan pertumbuhan pohon di preview belum diterapkan. Ekspor memakai JSON preview versi 5 (atau versi 6 bila ada arah pohon), hanya untuk preview; Android belum mendukung format ini. Data preview dan Android tetap terpisah.

Di Android sprite pohon jeruk berbuah matang pada sistem pohon yang sudah ada diperbarui ke desain pixel art; tahap tidak berbuah masih memakai sprite lama. Katalog editor Android tidak dibuat. Perubahan Android belum diuji lewat build atau perangkat.

Titik pijak visual pohon jeruk berada di perpotongan tengah tapak 2×2; bayangan dan hit testing preview memakai titik yang sama. Pada permukaan bertingkat, tinggi tapak juga diperhitungkan. Koordinat yang disimpan tetap sudut pertama tapak, sehingga world lama tidak dipindahkan. Renderer Android untuk pohon jeruk datar disesuaikan ke pusat tapak, tetapi belum diuji melalui build atau perangkat.
