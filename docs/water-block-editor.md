# Block Air di Map Editor

Pilih **Block → Air** untuk mengganti permukaan, mengisi sel kosong atau menumpuk block seperti jenis lainnya. Tinggi tiap block bertingkat sama dengan pita rumput pulau. Editor menampilkan thumbnail dari konsep air bening pilihan.

Di preview, permukaan dan sisi air digambar dengan alpha 64% dan diberi riak ringan. Air yang ditumpuk menyatu secara visual dengan block atau latar di belakangnya; air pada tingkat dasar menampilkan warna dasar perairan. Ini tampilan transparan nyata, tetapi merupakan ilustrasi 2D berlapis, bukan simulasi optik, aliran, atau permukaan yang bergelombang secara fisik. Perilaku berjalan dan penyimpanan terrain tidak berubah.

Android menggunakan warna, dasar perairan, transparansi dan riak serupa untuk terrain datar yang sudah didukung. World bertingkat versi 4 masih hanya bisa dibaca preview; data browser dan Android terpisah. Android belum diuji di perangkat untuk perubahan tampilan ini.
