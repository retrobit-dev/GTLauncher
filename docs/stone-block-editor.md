# Block Batu di Map Editor

Pilih **Block → Batu**. Gunakan **Ganti block** untuk mengganti block teratas dan **Tambah block** untuk menambah tingkat atau mengisi sel kosong; **Hapus** menghapus tingkat teratas. Undo/Redo dan perlindungan posisi karakter/rumah berlaku seperti jenis block lainnya.

Permukaan memakai warna abu-abu hangat, retakan tipis dan bintik mineral yang terinspirasi dari konsep pilihan. Thumbnail editor diekstrak dari konsep tersebut. Bentuk block tetap menggunakan geometri dan tinggi editor yang ada; detail permukaan digambar ulang secara prosedural, bukan menempelkan konsep sebagai tekstur. Kode terrain tetap 4 dan world lama tidak dimigrasi.

Preview dapat menyimpan block bertingkat. Android memakai palet dan detail yang sepadan untuk world datar yang didukung; world bertingkat versi 4 masih hanya tersedia di preview. Penyimpanan browser dan Android terpisah, dan tampilan Android belum diuji di perangkat.
